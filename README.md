
# Bar-da-meire

## Sobre o projeto

O Bar-da-meire é um projeto desenvolvido com o objetivo de auxiliar na organização e apresentação dos produtos de um bar, facilitando a visualização de bebidas, categorias e preços.

O projeto surgiu como uma iniciativa de desenvolvimento de uma solução digital para um negócio real, buscando aplicar conhecimentos de programação na criação de uma ferramenta útil no dia a dia.

## Objetivos

- Organizar produtos por categorias.
- Facilitar a visualização dos produtos e preços.
- Criar uma solução digital voltada a um negócio real.
- Aplicar conhecimentos de desenvolvimento de software na prática.
